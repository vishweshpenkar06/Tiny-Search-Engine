# Context Managers in Python

The with statement uses a context manager to set up and tear down a resource reliably. File handling is the most common case: with open(path) as handle guarantees the file is closed even when the body raises.

A context manager implements enter and exit methods, or uses contextlib.contextmanager with a generator. The exit method can suppress an exception by returning true.

Use context managers for locks, database connections, and temporary directories. They remove duplicated try and finally blocks, and they make the lifetime of a resource visible at the point of use.
