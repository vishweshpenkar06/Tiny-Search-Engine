# Python Generators

A generator yields values one at a time with the yield keyword. Because it produces items lazily, it keeps memory flat even for a very large or infinite stream.

Generators are single use: after iteration finishes the object is exhausted. Use itertools.tee when two consumers need the same stream. A generator expression such as (line for line in file) is the comprehension form and is preferred for simple pipelines.

Compared with returning a list, a generator avoids allocating the whole result up front. That makes it a good fit for streaming pipelines and memory constrained workers. Reading a large file line by line is the classic example.
