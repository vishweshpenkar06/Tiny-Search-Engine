# Python Decorators

A decorator wraps a function to add behaviour without changing its body. The at-syntax is shorthand for assigning the wrapped function back to its name.

Common uses include caching, logging, timing, and access control. functools.lru_cache memoizes results, while functools.wraps preserves the original name and docstring for introspection.

Decorators can accept arguments by returning a decorator function from an outer factory. Keep them transparent: the wrapper should preserve signatures and should not swallow exceptions unless that is the stated purpose.
