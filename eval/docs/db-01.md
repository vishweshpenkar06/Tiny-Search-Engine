# SQLite Indexes and Query Plans

An index on a SQLite column lets the query planner find rows without scanning the whole table. Create an index with CREATE INDEX on the columns used in WHERE and JOIN clauses.

Use EXPLAIN QUERY PLAN to see whether a query uses an index or a full table scan. Composite indexes follow the leftmost prefix rule, so column order matters.

Indexes speed up reads but slow down writes because every insert must update each index. Keep only indexes that a measured query actually needs.
