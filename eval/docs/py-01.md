# Python List Comprehensions

A list comprehension builds a new list from an iterable in a single readable expression. It replaces a loop plus an append call with a compact syntax, and it can include an optional filter clause.

Example: squares = [n * n for n in range(10) if n % 2 == 0]. The expression is evaluated once per item that passes the filter. Nested comprehensions flatten sequences but should stay short for readability.

Comprehensions also exist for dictionaries and sets. They are usually faster than an explicit loop because the list is preallocated by the interpreter. Use a generator expression instead when the result is consumed once and memory matters.
